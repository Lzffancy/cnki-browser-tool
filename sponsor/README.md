# 赞助

如果这个工具帮你省了事，欢迎请作者喝杯咖啡。

## 收款码放这里

把两张收款码图片放到本目录，并严格命名为：

| 文件名 | 用途 |
|---|---|
| `wechat.png` | 微信收款码 |

> 图片格式需为 `.png`，与 `.github/FUNDING.yml` 里写的扩展名保持一致。若你的收款码是 `.jpg`，改一下 `FUNDING.yml` 里的链接扩展名即可，二者保持一致就行。

放好后，仓库主页右上角会出现 **Sponsor** 按钮，点击即可看到微信赞助入口。

## 隐私提示

收款码会随仓库公开。个人收款码只暴露收款信息，不暴露你的银行卡号等敏感信息；若在意，建议单独注册一个「打赏专用」收款码。
